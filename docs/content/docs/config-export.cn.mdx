<Callout type="info">导出你的数据库连接配置（含加密密码），用 AES-256-GCM 加密保护，安全地在不同电脑之间迁移。默认使用加密导出。</Callout>

<Callout type="warn">这里导出的是 DBX 连接配置，不包含业务数据库的表结构或数据，也不是数据库备份。数据库内容请使用 [数据库导出](/cn/docs/database-export) 或 [数据库备份](/cn/docs/database-backup)。</Callout>

## 导出

<Steps>
<Step>
    ### 发起导出

    点击侧边栏顶部的 **导出** 按钮。
  </Step>
<Step>
    ### 选择连接

    勾选一个或多个连接。默认全选。最终只会导出已选连接、相关的侧边栏分组和排序，以及引用的隧道配置（Tunnel Profile）。
  </Step>
<Step>
    ### 选择导出保护

    输入密码短语来加密连接密码。仅在可信环境下临时迁移时，也可以选择**不加密导出**并确认风险。明文导出默认不包含凭据；如需保留，须在确认前明确勾选**包含密码和其他凭据（明文）**。
  </Step>
<Step>
    ### 保存文件

    选择保存位置。导出文件只包含已选连接、相关布局和引用的 Tunnel Profile。推荐使用加密导出。
  </Step>
</Steps>

## 导入

<Steps>
<Step>
    ### 发起导入

    点击侧边栏顶部的 **导入** 按钮。
  </Step>
<Step>
    ### 选择文件并解密

    选择导出的文件。DBX 会自动识别加密和明文配置文件；加密文件会先要求输入密码短语，DBX 会先解密并预览，此时不会写入本地连接。
  </Step>
<Step>
    ### 选择连接

    勾选文件中要导入的连接。默认全选。
  </Step>
<Step>
    ### 完成

    只有已选连接会被导入，密码自动恢复。按 名称 + 主机 + 端口 自动去重。已选连接的侧边栏分组和排序仍可在导入后选择应用。
  </Step>
</Steps>

## CLI 与 MCP 导入

本地 DBX 导出可用 `dbx connections import --file connections.json --json` 预览，检查数量和警告后添加 `--yes` 执行。MCP 的 `dbx_import_connections` 接收 `file_path`；省略 `confirmed` 时仅预览，获得批准后传 `confirmed: true`。凭据保留在受保护的本地文件中，不进入工具参数或结果。

这两个接口以事务方式仅追加导入，包含支持的完整连接设置、被引用的隧道配置和侧边栏分组/排序，并重新映射 ID。只有规范化名称、主机、端口、数据库类型和数据库均相同的连接才会跳过；同名但端点、类型或数据库不同的连接分别保留，不覆盖已有设置或凭据。输入文件上限为 16 MiB，Unix 下须仅所有者可访问。此功能仅支持本地模式，通常需要已初始化的加密存储，并遵守 MCP 策略。CLI 可对完全为空的配置明确使用 `--initialize`，有已有连接或旧版凭据时拒绝，预览不创建密钥。加密导出须添加 CLI `--passphrase-file passphrase.txt` 或 MCP `passphrase_file`，指定单独的仅所有者可访问 UTF-8 文件；不要在命令参数或工具调用中传递口令字面值。详见 [CLI 导入](/cn/docs/cli#导入-dbx-连接包)。

## 安全性

- 密码使用 **AES-256-GCM** 加密，密钥通过 **PBKDF2** 派生
- 加密文件没有密码短语无法解密
- 明文导出默认不包含密码和其他凭据。勾选**包含密码和其他凭据（明文）**后，这些信息可以被直接读取；仅用于可信环境下的临时迁移，请妥善保管文件并在使用后删除
- 导出文件是标准 JSON 格式，可以通过 U 盘、网盘等方式传输
- DBX 会把普通连接字段与数据库密码、SSH 密码、SSH 密钥密码、完整连接字符串等密钥信息分开存储。加密导出会保护组合后的数据；明文导出仅在本次明确勾选包含凭据时，才会把这些敏感信息写成可直接读取的 JSON。取消或关闭明文确认对话框、完成导出后，此选项会重置。
- 请把导出口令当作密钥管理。任何人同时拿到导出文件和口令，都可以恢复其中的连接。

## 向后兼容

导入会自动识别加密或明文配置文件，也支持旧版本导出的明文 JSON 文件（不含密码）和原始的连接配置数组。

## 包含哪些内容

| 项目                                           | 是否包含                                             |
| ---------------------------------------------- | ---------------------------------------------------- |
| 连接名称、类型、主机、端口、数据库、颜色       | 包含                                                 |
| URL 参数、SSL、SSH、代理、可见数据库设置       | 包含                                                 |
| 数据库密码、SSH 密码、SSH 密钥密码、连接字符串 | 加密导出包含；明文导出仅在明确勾选包含凭据时包含           |
| 厂商 JDBC 驱动 JAR 文件                        | 不包含；目标机器需要重新安装或导入                   |
| 已选连接的侧边栏分组和排序                     | 包含；导入连接后可选择是否应用                       |
| 已保存 SQL 和界面/编辑器设置                   | 不包含；需要迁移时使用 [云同步](/cn/docs/cloud-sync) |

如果要迁移 JDBC 连接，先在这里导出连接配置，再在目标机器通过 [JDBC 插件](/cn/docs/plugins) 安装插件并导入驱动 JAR。
