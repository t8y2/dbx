---
title: 收藏夹
description: 将常用表、视图钉到按数据库分组的收藏夹中，支持备注、自定义子分组与云同步。
---

收藏夹可以让你把最常用的表、视图、物化视图"钉"到侧边栏，每个数据库一组，点击即达。加入收藏后，对应数据库侧边栏会多出一个 **收藏夹** 分组。

## 可以收藏哪些对象

收藏夹按数据库划分，因此右侧侧边栏会为每个 `(连接, 数据库)` 组合显示独立的 **收藏夹** 组，组内可以再细分：

- **默认分组**：首次加入收藏时自动创建
- 任意数量的自定义子分组（例如「日报表」「中间表」）

可收藏对象包括：

- 表（table）
- 视图（view）
- 物化视图（materialized view）

## 添加收藏

<Steps>
  <Step>
    ### 打开右键菜单 在侧边栏中右键点击要收藏的表或视图。
  </Step>
  <Step>
    ### 选择「加入收藏」 该对象会被加入所属数据库的**默认分组**。如果分组处于折叠状态，收藏项依然会被持久化；展开分组即可看到。
  </Step>
</Steps>

## 管理收藏项

点击 **收藏夹** 标题展开后，可以：

- **重命名分组** 让分组更易识别
- **删除分组**（组内项会回到默认分组）
- **移动收藏项** 到其他分组，或在当前分组内调整顺序
- **编辑备注** 说明用途或常用查询条件
- **移除收藏** 不再需要时
- **清空当前数据库的收藏**（在分组标题右键菜单中）

## 备注

每条收藏支持一段自由文本备注。当表名含义不直观（如 `t_evt_2024_q3`）或希望以特定过滤条件打开时，备注非常有用。备注与收藏一起保存，会显示在项的 tooltip 中。

## 顺序与拖拽排序

分组和收藏项都支持排序。在侧边栏直接拖拽即可调整顺序，也可以使用右键菜单中的「移到顶部 / 移到底部」。顺序会被持久化，并通过云同步跨设备保持一致。

## 云同步

收藏夹状态是 DBX 通过 WebDAV / GitHub / Gitee 同步的快照的一部分（参见 [云同步](/docs/cloud-sync)），可在登录同一 DBX 账户的机器之间无缝漫游。

- 旧版本生成的快照不包含 `favorites_state` 字段，应用到新版本时会保留本机收藏不动。
- 新版本生成的快照始终包含该字段（旧版本会安全忽略）。

## 从旧版 Pin 自动迁移

更早版本的 DBX 把收藏存放在「置顶侧边栏项」中。本次更新首次启动时会扫描现有的置顶集合，把其中可识别的 v2 pin（表/视图/物化视图）静默迁移到新的收藏夹中；非收藏类的 pin（连接、模式等）保持原状。

通常无需手动干预；如果有特殊排查需求，可以执行 `pnpm dbx dev -- --migrate-favorites`（高级用法）。

## 存储位置

收藏夹与其他本地设置一起存放在 `app_settings.json` 的 `favorites_state` 字段中。整组状态以单一 JSON 文档形式保存，组和项的更新是原子的，不会出现半写入状态。

如需独立备份，复制 `favorites_state` 字段即可：

- **macOS**：`~/Library/Application Support/com.dbx.app/app_settings.json`
- **Linux**：`~/.config/com.dbx.app/app_settings.json`
- **Windows**：`%APPDATA%\com.dbx.app\app_settings.json`

## 使用建议

- 按用途而非按 schema 分组：相比按 schema 划分，「日报表」「参考数据」更易扫读。
- 在备注里直接写常用过滤条件，例如 `WHERE created_at > now() - interval '7 days'`，比写一句泛泛的注释更高效。
- 把收藏和 [SQL 代码片段](/docs/sql-snippets) 配合使用，最常用的查询一触即达。
