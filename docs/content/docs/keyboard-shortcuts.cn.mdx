DBX 的快捷键来自同一份可配置 action registry。**设置 → 快捷键**显示当前版本和当前平台的实际绑定，是默认键变化或用户自定义后的权威来源。

`Mod` 表示 macOS 的 `Cmd`，Windows/Linux 的 `Ctrl`。

## 常用默认快捷键

### SQL 编辑器

| 默认键 | 操作 |
| --- | --- |
| `Mod+Enter` | 执行当前语句或选中 SQL |
| `Mod+\` | 在新的结果标签页执行 |
| `Shift+Mod+F` | 格式化 SQL |
| `Mod+/` | 切换行注释 |
| `Mod+S` | 保存 SQL |
| `Tab` | 接受补全 |
| `Shift+Tab` | 减少缩进 |
| `Mod+D` | 复制当前行 |
| `Shift+Mod+K` | 删除当前行 |
| `Alt+↑` / `Alt+↓` | 上下移动当前行 |
| `Shift+Alt+↑` / `Shift+Alt+↓` | 向上/下复制当前行 |
| `Shift+Alt+U` / `Shift+Alt+L` | 选中内容转大写/小写 |
| `Mod+.` | 折叠或展开代码块 |
| `Mod+Shift+A` | 把选中内容发送给 AI |

当前 registry 没有“执行全部 SQL”的默认 action。需要运行多条语句时，选中范围执行或使用编辑器提供的多语句执行入口，不要依赖旧文档中的 `Ctrl/Cmd+Shift+Enter`。

### 表格和数据

| 默认键 | 操作 |
| --- | --- |
| `F5` | 刷新当前数据 |
| `Mod+D` | 复制当前行 |
| `Delete` | 标记删除当前行 |
| `Tab` | 切换转置视图 |

普通复制/粘贴仍遵循平台标准按键，但“复制当前行”“删除当前行”和“切换转置”是 DBX 可配置 action。

### 全局和导航

| 默认键 | 操作 |
| --- | --- |
| `Mod+T` | 新建查询 |
| `Mod+P` | 快速打开 |
| `Mod+W` | 关闭当前标签页 |
| `Shift+Mod+[` / `Shift+Mod+]` | 上一个/下一个标签页 |
| `Mod+1` … `Mod+9` | 切换到指定标签页 |
| `Mod+B` | 显示或隐藏侧边栏 |
| `Mod+=` / `Mod+-` / `Mod+0` | 放大、缩小、重置 UI 缩放 |

侧边栏还提供可配置的复制、粘贴、编辑连接和按住修饰键在新标签页打开数据等 action。

## 快速打开

按 `Mod+P` 搜索当前工作区中的连接、数据库、Schema、表、视图和保存的 SQL。结果来自已加载和可搜索的对象；大型连接尚未加载元数据时，先展开或刷新对应节点。

## 自定义和冲突

1. 打开 **设置 → 快捷键**
2. 选择 action 并进入录制
3. 按下新组合键；也可以清空不需要的绑定
4. 处理冲突后保存

DBX 会检测同一作用域中的冲突。编辑器、表格、搜索、侧边栏和全局 action 具有不同作用域，但浏览器、操作系统、输入法或辅助功能仍可能先占用按键。

Windows/Linux 上 `Ctrl+Alt` 可能被键盘布局当作 AltGr；DBX 对相关组合采取更保守的匹配。macOS 的 Option+字母可能产生变形字符，DBX 会在安全情况下使用物理键位回退。
