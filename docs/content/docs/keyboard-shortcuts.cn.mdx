DBX 的快捷键来自同一份可配置 action registry。**设置 → 快捷键**显示当前版本和当前平台的实际绑定，是默认键变化或用户自定义后的权威来源。

`Mod` 表示 macOS 的 `Cmd`，Windows/Linux 的 `Ctrl`。

## 常用默认快捷键

### SQL 编辑器

| 默认键 | 操作 |
| --- | --- |
| `Mod+Enter` | 执行当前语句或选中 SQL |
| `Mod+\` | 在新的结果标签页执行 |
| `Shift+Mod+F` | 格式化 SQL |
| `Mod+/` | 切换行注释 |
| `Mod+S` | 保存 SQL |
| `Tab` | 接受补全 |
| `Shift+Tab` | 减少缩进 |
| `Mod+D` | 复制当前行 |
| `Shift+Mod+K` | 删除当前行 |
| `Alt+↑` / `Alt+↓` | 上下移动当前行 |
| `Ctrl+↑` / `Ctrl+↓`（Windows/Linux），`Ctrl+Alt+↑` / `Ctrl+Alt+↓`（macOS） | 编辑器上下滚动一行，不移动光标或选区 |
| `Shift+Alt+↑` / `Shift+Alt+↓` | 向上/下复制当前行 |
| `Mod+Shift+U` | 切换选中内容大小写（首次默认转为大写） |
| `Shift+Alt+U` / `Shift+Alt+L` | 选中内容转大写/小写 |
| `Shift+Alt+C` | 切换选中内容的命名风格（camelCase → PascalCase → snake_case → SCREAMING_SNAKE_CASE → kebab-case） |
| `Mod+.` | 折叠或展开代码块 |
| `Mod+Shift+A` | 把选中内容发送给 AI |

当前 registry 没有“执行全部 SQL”的默认 action。需要运行多条语句时，选中范围执行或使用编辑器提供的多语句执行入口，不要依赖旧文档中的 `Ctrl/Cmd+Shift+Enter`。

### 表格和数据

| 默认键 | 操作 |
| --- | --- |
| `F5` | 刷新当前数据 |
| `Mod+D` | 复制当前行 |
| `Delete` | 标记删除当前行 |
| `Tab` | 切换转置视图 |

普通复制/粘贴仍遵循平台标准按键，但“复制当前行”“删除当前行”和“切换转置”是 DBX 可配置 action。

「聚焦 WHERE 条件输入框」默认不绑定快捷键。可在 **设置 → 快捷键 → 数据表格** 中自行设置，按下已配置的快捷键后将光标移至当前表数据标签页的 WHERE 输入框，保留现有条件且不执行查询。WHERE 输入框不可用时不生效。

网格还有两个固定手势（不可自定义）：光标停在当前显示的最后一行时按 `↓` 会在结果末尾追加一行（与「新增行」按钮不同，按钮跟随「插入位置」设置）；编辑器内的 `Esc` 只取消本次输入，焦点回到网格后按 `Esc` 会撤掉未填写过的新增行，否则把当前单元格回退为原值。详见[数据表格](/cn/docs/data-grid)。

### 全局和导航

| 默认键 | 操作 |
| --- | --- |
| `Mod+T` | 新建查询 |
| `Mod+P` | 快速打开 |
| `Mod+W` | 关闭当前标签页 |
| `Ctrl+Alt+←` / `Ctrl+Alt+→` | 后退/前进标签页访问历史 |
| `Shift+Mod+[` / `Shift+Mod+]` | 左侧/右侧标签页 |
| `Mod+1` … `Mod+9` | 切换到指定标签页 |
| `Mod+B` | 显示或隐藏侧边栏 |
| `Mod+=` / `Mod+-` / `Mod+0` | 放大、缩小、重置 UI 缩放 |

侧边栏还提供可配置的复制、粘贴、编辑连接和按住修饰键在新标签页打开数据等 action。

## 快速打开

按 `Mod+P` 搜索当前工作区中的连接、数据库、Schema、表、视图和保存的 SQL。结果来自已加载和可搜索的对象；大型连接尚未加载元数据时，先展开或刷新对应节点。

## 自定义和冲突

1. 打开 **设置 → 快捷键**
2. 选择 action 并进入录制
3. 按下新组合键；也可以清空不需要的绑定
4. 处理冲突后保存

DBX 会检测同一作用域中的冲突。编辑器、表格、搜索、侧边栏和全局 action 具有不同作用域，但浏览器、操作系统、输入法或辅助功能仍可能先占用按键。

快捷键页签的搜索框还支持**键盘录入**：点击搜索框右侧的键盘图标，直接按下组合键即可筛出绑定该组合的 action；跨作用域共用同一组合的 action 会一并列出，排查冲突时不必先知道组合键的写法。录入期间按下的组合键不会触发真实命令；`Esc` 退出录入，`Backspace` 清空已录入的组合。也可以在搜索框里直接输入文本形式，`Ctrl+T` 与 `Ctrl + T` 都能命中。

**被系统抢占的组合无法录入**：`Alt+F4`、`Win` 键、`Ctrl+Alt+Del`、macOS 的 `⌘Tab` 这类按键先被操作系统或窗口管理器处理，DBX 收不到，录制时不会有任何结果（也不是录入失败）。这类组合即使手工配置了绑定也不会触发，排查时请改用文本搜索。

Web 形态还要多一层：浏览器自己保留的按键（`Ctrl+W` / `Ctrl+Shift+W` / `Ctrl+T` / `Ctrl+N` 等，macOS 的 `⌘W`）由浏览器直接处理，页面拿不到事件。桌面形态没有这条限制——`Ctrl+Shift+W` 是「关闭窗口」的默认键，`Ctrl+W` 是「关闭标签页」的默认键，都可以正常录入。

Windows/Linux 上 `Ctrl+Alt` 可能被键盘布局当作 AltGr；DBX 对相关组合采取更保守的匹配。macOS 的 Option+字母可能产生变形字符，DBX 会在安全情况下使用物理键位回退。
