---
title: 对象浏览器
description: 使用列表或网格集中查看数据库对象、统计信息、源码和批量操作。
---

对象浏览器把当前数据库或 Schema 中的对象集中到一个可搜索的列表/网格中。它适合对象数量很多、需要按类型和元数据筛选，或需要批量处理多个对象的场景。

## 适合的场景

- 在一个页面查看大量表、视图、过程、函数、序列和其他对象
- 按名称、类型、Schema、注释或统计信息筛选
- 比较表大小、行数、创建/更新时间等驱动可提供的信息
- 多选对象后执行打开、复制、导出、删除或其他批量操作
- 在不展开深层对象树的情况下快速查看 DDL 或源码

## 打开方式

从连接、数据库或 Schema 的上下文菜单打开**对象浏览器**。DBX 会根据当前节点确定 Catalog、数据库和 Schema 范围。

对象浏览器可以作为主标签页或侧边面板打开。侧边面板适合一边查看对象列表，一边保留当前查询或数据标签。

## 视图与筛选

| 功能 | 说明 |
| --- | --- |
| 列表视图 | 适合查看名称、类型、Schema、注释、行数和大小等列 |
| 网格视图 | 适合快速扫描对象卡片和主要摘要 |
| 对象类型筛选 | 默认优先显示表，也可以切换视图、例程和其他类型 |
| 搜索 | 按对象名称、Schema、类型和部分元数据过滤 |
| 列调整 | 调整列宽、显示列和滚动位置；视口状态可以保留 |

统计列只在驱动能够可靠读取时显示。大型数据库读取行数或大小可能有额外开销，必要时关闭不需要的统计信息。

## 对象操作

单击或双击对象可以按类型打开：

- 表和视图数据
- 表结构、字段、索引、外键、触发器和 DDL
- 视图、过程、函数、触发器等对象源码
- Oracle、OceanBase Oracle、Dameng 的 TYPE 详情和只读 TYPE/TYPE BODY 源码
- 数据库专属管理界面

上下文菜单还可以提供：

- 复制名称、限定名称或 DDL
- 生成查询 SQL
- 导入、导出、传输和结构相关入口
- 打开 ER 图、字段血缘或 Schema 对比
- 重命名、清空、删除或管理对象

具体操作由数据库 capability、连接只读状态和当前权限决定。

## 从 Schema 管理索引

Oracle、OceanBase Oracle 和达梦支持 Schema 索引分组与对象浏览器的**索引**筛选，也适用于对应方言的 JDBC 连接。OceanBase JDBC 须明确使用 Oracle 模式 URL；普通 OceanBase/MySQL URL 不会被推断为 Oracle 模式。新入口需要驱动提供精确对象身份；提示无法核实时，更新 Agent 或 JDBC 插件并重新连接。原表级入口保持原有使用条件。

Schema 索引只在索引分组或**索引**筛选中按页加载，不混入**全部**列表。窄窗口中可从工具栏的更多操作菜单切换筛选。

### 新增第一个索引

1. 打开 Schema 的索引分组菜单，或切换对象浏览器的**索引**筛选，点击**新增索引**。空列表也提供此入口。
2. 搜索并选择当前连接、数据库和 Schema 中可见的父表，确认后进入该表的结构编辑器。选表和导航不执行 DDL。
3. 在自动添加的索引草稿中选择列、填写名称，检查 SQL 预览，再应用。生产连接仍须经过原有确认。

### 查看、修改和删除

- 在索引筛选中搜索名称，使用**加载更多**查看后续结果，或刷新当前列表。复制名称保留字典中的大小写和空格。
- 查看索引时，信息面板读取真实父表的索引、列和 DDL。同 owner 索引可进入父表结构编辑器，并精确定位原索引；已有未保存草稿会保留。
- 修改索引后，检查可能包含删除和重建的 SQL，再应用。**删除索引**或 Delete 只进入父表的删除草稿，不直接执行 `DROP INDEX`；应用前可撤销删除标记。
- 索引与父表 owner 不同，或无法核实索引 owner 时，新入口只读查看；缺少父表身份时保留复制和刷新，不猜测目标。约束支撑索引、不完整元数据和不支持的索引类型仍由原编辑器阻断或引导处理。

已应用后若元数据刷新失败，界面保留已应用结果并提供刷新重试；重试不会重新执行 DDL。部分成功或结果未知时，先核对逐条结果并刷新数据库状态，再处理剩余草稿。

## 多选与批量操作

对象浏览器支持复选框多选。批量操作可能包括：

- 打开或复制多个对象名称
- 批量导出或生成 SQL
- 删除、清空或截断所选表
- Schema 索引按父表逐项管理，不执行集中批量删除，也不参与表复制和表导出
- 对 PostgreSQL 等数据库使用带 `CASCADE` 的批量对象操作

<Callout type="warn">批量删除、清空和截断可能影响大量对象。生产环境先确认所选范围、生成 SQL、备份和依赖关系。</Callout>

## DDL 与源码

- **查看 DDL**优先读取数据库或驱动提供的定义
- **对象源码**用于视图、过程、函数、触发器等对象；Oracle、OceanBase Oracle、Dameng 的 TYPE/TYPE BODY 源码为只读
- 在这三种数据库中，打开 TYPE 行可查看属性、方法、集合信息、状态和当前可见的 TYPE BODY 配对；使用“源码”标签查看或复制定义
- 若列表中存在 TYPE BODY，可单独打开该行查看源码；它与同名 TYPE 分开读取
- 源码视图支持搜索；数据库和对象允许时，可以打开到编辑器修改
- 保存源码或执行 DDL 前会进入只读、生产保护和危险操作检查

DBX 显示的是当前驱动能获取到的定义。格式、是否包含权限/注释/存储属性，以及能否直接编辑，都会因数据库而异。
元数据区域会标明信息不完整、不可用或不支持；只有成功读取的空区域才会显示为空。

通过通用 JDBC 连接 OceanBase Oracle 模式时，使用显式 `jdbc:oceanbase:oracle://` URL，使类型列表、详情和源码采用一致的方言。普通 `jdbc:oceanbase://` URL 不会据此推断为 Oracle 模式。

## 查看和修改 Oracle 系触发器

Oracle、OceanBase Oracle 和 DM8 的精确触发器入口按实际驱动与版本开放；旧 Agent、未识别方言或缺少元数据的插件不会自动获得写入能力。原生 Oracle 和 DM8 的实库兼容性仍待验证，不能以 OceanBase 的验证结果替代。

1. 选择「触发器」筛选，按名称定位对象，按需加载更多。单击打开源码侧栏。需要源码标签时，从对象树按当前源码打开设置进入。
2. 核对触发器 owner、真实所属表/视图或非表级作用域。「启用/禁用」和「有效/无效」是独立状态；读取失败或无权限也会单独显示。
3. 修改完整定义并保存，在确认框核对目标、执行 Schema 和实际 SQL。只有正文、截断内容或无法确认的基线不能直接替换对象；可以保留人工补全的候选，补齐权限后显式重读，再重新预览。
4. 查看权威读回结果。数据库接受语句不代表触发器有效；存在编译错误时，在同一详情中查看错误或进入无效对象诊断，再返回源码修正。只有能准确映射到当前源码的错误位置才定位光标。

源码、依赖和被依赖沿用同一详情面板。依赖导航和所属对象入口使用实际 owner/type；非表级触发器没有表导航。切换详情分区保留草稿及撤销记录；关闭或切换对象时，可以取消弃稿。触发器源码刷新与失败后的重试保留最新输入，不自动覆盖草稿。

启停和编译使用原生操作，不通过删建模拟。Oracle/OceanBase 修改会保全已知的禁用状态；DM 的状态恢复可能包含独立步骤，编译失败后不会自动重新启用。

<Callout type="warn">DDL 可能逐条提交。结果未知或部分成功时，先用「只读核实」或刷新读取实际状态；DBX 不自动重放已尝试的写入。保留失败草稿，核实后仅为剩余修改生成新预览。对象或定义已变化时，先重读并核对差异。</Callout>

## 与对象树的区别

| 对象树 | 对象浏览器 |
| --- | --- |
| 适合层级导航和固定常用对象 | 适合集中筛选和比较大量同级对象 |
| 展开后查看字段和子节点 | 通过列、卡片和侧面板查看摘要 |
| 强调上下文菜单和拖拽 | 强调搜索、多选和批量操作 |

两者共享对象身份和元数据。可以从对象浏览器打开对象，再回到对象树定位对应节点。

## 功能边界

- 不同数据库公开的对象类型和统计列不同
- 行数和大小可能是估算值或缓存值
- 系统对象是否显示取决于可见 Schema 和系统 Schema 设置
- 只读连接仍可查看对象、DDL 和源码，但修改入口会被禁用或拒绝
- 大量对象首次加载时，驱动可能分批读取元数据
