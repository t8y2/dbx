---
title: 对象浏览器
description: 使用列表或网格集中查看数据库对象、统计信息、源码和批量操作。
---

对象浏览器把当前数据库或 Schema 中的对象集中到一个可搜索的列表/网格中。它适合对象数量很多、需要按类型和元数据筛选，或需要批量处理多个对象的场景。

## 适合的场景

- 在一个页面查看大量表、视图、过程、函数、序列和其他对象
- 按名称、类型、Schema、注释或统计信息筛选
- 比较表大小、行数、创建/更新时间等驱动可提供的信息
- 多选对象后执行打开、复制、导出、删除或其他批量操作
- 在不展开深层对象树的情况下快速查看 DDL 或源码

## 打开方式

从连接、数据库或 Schema 的上下文菜单打开**对象浏览器**。DBX 会根据当前节点确定 Catalog、数据库和 Schema 范围。

对象浏览器可以作为主标签页或侧边面板打开。侧边面板适合一边查看对象列表，一边保留当前查询或数据标签。

## 视图与筛选

| 功能 | 说明 |
| --- | --- |
| 列表视图 | 适合查看名称、类型、Schema、注释、行数和大小等列 |
| 网格视图 | 适合快速扫描对象卡片和主要摘要 |
| 对象类型筛选 | 默认优先显示表，也可以切换视图、例程和其他类型 |
| 搜索 | 按对象名称、Schema、类型和部分元数据过滤 |
| 列调整 | 调整列宽、显示列和滚动位置；视口状态可以保留 |

统计列只在驱动能够可靠读取时显示。大型数据库读取行数或大小可能有额外开销，必要时关闭不需要的统计信息。

## 对象操作

单击或双击对象可以按类型打开：

- 表和视图数据
- 表结构、字段、索引、外键、触发器和 DDL
- 视图、过程、函数、触发器等对象源码
- 数据库专属管理界面

上下文菜单还可以提供：

- 复制名称、限定名称或 DDL
- 生成查询 SQL
- 导入、导出、传输和结构相关入口
- 打开 ER 图、字段血缘或 Schema 对比
- 重命名、清空、删除或管理对象

具体操作由数据库 capability、连接只读状态和当前权限决定。

## 多选与批量操作

对象浏览器支持复选框多选。批量操作可能包括：

- 打开或复制多个对象名称
- 批量导出或生成 SQL
- 删除、清空或截断所选表
- 删除所选索引
- 对 PostgreSQL 等数据库使用带 `CASCADE` 的批量对象操作

<Callout type="warn">批量删除、清空和截断可能影响大量对象。生产环境先确认所选范围、生成 SQL、备份和依赖关系。</Callout>

## DDL 与源码

- **查看 DDL**优先读取数据库或驱动提供的定义
- **对象源码**用于视图、过程、函数、触发器和其他可编辑对象
- 源码视图支持搜索；数据库和对象允许时，可以打开到编辑器修改
- 保存源码或执行 DDL 前会进入只读、生产保护和危险操作检查

DBX 显示的是当前驱动能获取到的定义。格式、是否包含权限/注释/存储属性，以及能否直接编辑，都会因数据库而异。

## 与对象树的区别

| 对象树 | 对象浏览器 |
| --- | --- |
| 适合层级导航和固定常用对象 | 适合集中筛选和比较大量同级对象 |
| 展开后查看字段和子节点 | 通过列、卡片和侧面板查看摘要 |
| 强调上下文菜单和拖拽 | 强调搜索、多选和批量操作 |

两者共享对象身份和元数据。可以从对象浏览器打开对象，再回到对象树定位对应节点。

## 功能边界

- 不同数据库公开的对象类型和统计列不同
- 行数和大小可能是估算值或缓存值
- 系统对象是否显示取决于可见 Schema 和系统 Schema 设置
- 只读连接仍可查看对象、DDL 和源码，但修改入口会被禁用或拒绝
- 大量对象首次加载时，驱动可能分批读取元数据
