---
title: Redis 工作台
description: 浏览、搜索和编辑 Redis Key，管理 TTL、Stream 消费组、Pub/Sub、Slowlog 和实例状态。
---

Redis 工作台把 Key 浏览、类型专属编辑、命令执行、实例观察和高风险命令保护放在一个连接中。它使用 `SCAN` 等增量方式处理键空间，避免把大型 Redis 实例一次性全部加载到界面。

## 数据库与别名

Redis 连接会列出可用的数字数据库。可以为 `db0`、`db1` 等设置本地别名，例如“订单缓存”或“开发环境”。别名只影响 DBX 显示和搜索，Redis 命令仍使用数字数据库编号。

扫描页大小保存在连接配置中。键很多或网络延迟较高时，减小页大小；需要更快浏览小实例时可以适当增大。

## Key 浏览与搜索

Key 列表可以显示名称、类型、值摘要、大小和 TTL。支持：

- 按 Redis 模式搜索，例如 `user:*`
- 使用模糊搜索，把普通关键词转换成包含匹配
- 在树形分组和扁平列表之间浏览
- 加载更多、获取全部或停止长时间扫描
- 复制 Key 名称、选择多个 Key 或选择当前已加载分组
- 按 Key、值或 Key + 值搜索

值搜索会读取匹配 Key 的内容，并针对 String、Hash 等类型做对应匹配。Hash 详情还可以单独搜索字段和值。

<Callout type="warn">“获取全部”和值搜索可能访问大量 Key。生产实例先使用具体模式缩小范围，并观察 Redis 延迟、CPU 和网络流量。</Callout>

## 数据类型

| 类型 | 主要能力 |
| --- | --- |
| String | 文本、JSON、多种显示格式；二进制字符串以转义文本只读展示 |
| Hash | 字段/值表格、搜索、排序、添加、编辑和删除字段 |
| List | 分页元素、索引、添加、编辑和删除 |
| Set | 成员浏览、添加和删除 |
| Sorted Set | 成员与分数浏览、编辑和删除 |
| Stream | 条目浏览、消费组、消费者、Pending、Lag 和投递详情 |
| RedisJSON | JSON 树/源码编辑、格式化和压缩；需要服务端 RedisJSON 模块 |

大型集合类型会分页加载。数量、已加载数量和继续加载入口会显示在详情中。

## 创建与编辑 Key

创建 Key 时选择数据类型并填写初始内容。可设置正整数 TTL；留空或按界面选择可创建永不过期 Key。

编辑现有值时，DBX 支持：

- 保留原 TTL
- 设为永不过期
- 设置相对 TTL 秒数
- 选择本地绝对过期时间
- JSON 源码格式化或压缩后保存
- 复制可重建当前值的插入命令（适用类型）

TTL 会自动倒计时，并可以在详情保持打开时定期刷新完整值。Key 在刷新前过期时，界面会提示并移除失效状态。

<Callout type="info">修改值时保留 TTL 可以避免把临时缓存意外变成永久 Key。保存前确认当前过期策略。</Callout>

## Stream 消费组

Stream 详情除了条目，还可以查看：

- 消费组和最后投递 ID
- 已读取数量和 Lag
- 消费者、空闲时间和非活跃状态
- Pending 条目、投递次数和归属消费者

这些数据来自 Redis 消费组命令，适合排查积压和未确认消息。它不是持续监控或告警系统。

## 命令行

命令行接受 Redis CLI 风格命令并显示结构化结果：

- 使用 ↑/↓ 浏览按连接保存的历史
- 清除当前命令历史
- 选择和复制文本结果
- 执行 `INFO`、`CLIENT LIST`、`CONFIG GET` 等命令
- 在支持的响应中查看表格或 JSON

工具栏的命令安全开关会分类 Redis 命令。部分危险命令需要确认，部分命令会默认阻止；关闭开关也不能绕过连接只读、生产保护或 MCP 策略。

## Pub/Sub

Pub/Sub 面板可以：

- 连接或断开订阅会话
- 订阅频道或模式
- 实时查看收到的消息
- 发布消息到指定频道
- 清空当前界面消息记录

Web/Docker 模式通过 WebSocket 维持订阅。反向代理部署时，需要允许对应 WebSocket 升级。

## Dashboard、Key 统计与 Slowlog

Redis Dashboard 展示服务端和实例信息，并把指标按区域折叠。根据服务端能力可以查看：

- 版本、运行时间、内存、客户端和连接状态
- Keyspace、命令、持久化、复制和集群摘要
- 每个 Key 的内存使用、空闲时间或访问相关统计
- Slowlog 条目、耗时、时间戳和集群节点

Key 统计和 Slowlog 会额外调用 Redis 命令。大型实例或集群中应限制范围和条目数量。

## 批量与破坏性操作

- 删除选中的 Key
- 删除当前分组中已加载的 Key
- 清空当前 Redis DB
- 对支持的结构执行批量字段/成员操作

清空 DB、批量删除和 `FLUSH*` 无法撤销。只读连接会拒绝写入；生产环境保护和危险命令规则会继续生效。

## 安全与性能建议

- 生产 Redis 使用只读账号或 ACL，并在 DBX 启用只读/生产保护
- 不要用 `KEYS *` 代替增量浏览；优先使用模式和 `SCAN`
- 值搜索、内存统计和 Slowlog 查询都可能增加服务端负载
- Stream 消费组详情会读取 Pending 和消费者状态，避免高频无限刷新
- 二进制值、模块命令和厂商扩展可能只能通过命令行查看
- MCP 暴露 Redis 时，普通写入和 `FLUSH*` 由不同权限级别控制
