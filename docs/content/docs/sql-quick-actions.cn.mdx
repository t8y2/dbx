---
title: SQL 快捷操作
description: 在查询编辑器中选中表名后，通过快捷键执行自定义 SQL 模板。
---

SQL 快捷操作允许你在查询编辑器中先选中表名（或限定标识符），再按快捷键执行可复用的 SQL 模板。

这与 [SQL 代码片段](/cn/docs/sql-snippets) 不同：代码片段通过补全把模板插入到光标处；快捷操作会根据当前选区生成 SQL，并走正常的执行流程。

## 管理快捷操作

打开 **设置 → 快捷键**，找到 **SQL 快捷操作** 区域。每条操作包含：

| 字段 | 作用 |
| --- | --- |
| 显示名 | 设置列表中显示的名称。 |
| 快捷键 | 触发该操作的按键组合。 |
| 状态 | 临时启用或停用，不需要删除模板。 |
| SQL 模板 | 执行前会把 `${table}` 替换为选中内容的 SQL。 |

你可以新增、编辑、启用、停用或删除操作。在编辑对话框中保存后会立即生效；也可以在设置窗口点击 **应用** 统一保存。

<Callout type="info">
  建议使用包含 `Mod`（macOS 为 `Cmd`，Windows/Linux 为 `Ctrl`）的组合键，比单独使用 `Shift+字母` 更少干扰正常输入。
</Callout>

## 执行快捷操作

1. 在 SQL 编辑器中选中表名或限定标识符，例如 `orders` 或 `public.users`。
2. 按下已配置的快捷键。
3. DBX 会把模板中所有 `${table}` 替换为去除首尾空白后的选区文本，并执行展开后的 SQL。

示例模板：

```sql
SELECT COUNT(*) FROM ${table}
```

选中 `orders` 后，DBX 会执行：

```sql
SELECT COUNT(*) FROM orders
```

如果没有选中任何内容，快捷键不会触发，编辑器会保持正常输入行为。

## 快捷键冲突

DBX 会检查快捷操作是否与以下快捷键冲突：

- 列表中的其他快捷操作
- **设置 → 快捷键** 中的内置编辑器和全局快捷键

存在冲突时，设置界面会标红，并且在解决冲突前无法 **应用** 设置。

## 保存、同步与安全

快捷操作属于编辑器设置，保存在当前 DBX 运行环境中。桌面版的[配置云同步](/cn/docs/cloud-sync)可以连同其他编辑器设置一起同步；[连接配置迁移](/cn/docs/config-export)只处理数据库连接，不包含快捷操作。

快捷操作只是生成 SQL，不会绕过数据库权限或 DBX 的生产保护。执行包含写入或 DDL 的模板前，仍应检查展开后的完整 SQL，并遵循[生产安全](/cn/docs/production-safety)建议。
