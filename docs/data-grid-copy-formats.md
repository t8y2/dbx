# 复制查询结果

在结果网格选择单元格或行后，右键菜单“复制”下有两种用途：

- **配置数据提取器…**：选择默认复制格式、调整各格式参数和菜单可见格式。只有点“保存”才会持久化；取消会丢弃草稿，“恢复默认”只恢复可见格式清单。普通复制和快捷键继续使用已保存的默认格式。
- **高级复制…**：为本次复制选择格式并调整参数，点“复制”立即复制，点“取消”丢弃更改。它不会修改默认格式、其他格式参数或菜单可见格式。预览默认收起，展开后才按当前参数生成；预览只读，不会写入剪贴板。

普通“复制为”菜单项仍按已保存参数立即复制。隐藏某个格式只影响菜单，不会改变默认复制/快捷键格式。

对话框左侧选择格式，右侧调整对应参数；高级选项默认折叠。要让调整用于以后的普通复制，在“配置数据提取器…”中保存。

## 适合粘贴到其他工具的格式

- **TSV、CSV、分隔值**：适合电子表格和文本编辑器。CSV 可设置表头位置（顶部、底部或无）、表头名称/注释、大小写、引号、公式防护、换行替代、数组括号和数字格式。公式防护会给危险文本加前缀；真正的数值负数不改写。换行替代和数组格式会改变文本表示，需按接收端调整。
- **HTML**：同次写入 `text/html` 富文本表格和 `text/plain` HTML 源码；支持富文本的目标可粘贴表格，其余目标可读取源码。
- **DbUnit Flat XML**：输出 `<dataset>` 和逐行表元素。NULL 输出 `[NULL]` 标记，需在 DbUnit `ReplacementDataSet` 配置该标记；若关闭 NULL 属性，首行 NULL 可能影响 DbUnit 的列识别。二进制值输出 Base64，不会自动生成数据库写入脚本。
- **PHP 数组**：可选 `array()` 或短数组语法、单双引号、日期 ISO 表现、行分隔符和变量名。重复列名会被拒绝，以免 PHP 数组键覆盖；无法无损表示的整数/decimal 保留为字符串，二进制以 Base64 解码表达式输出。

## 复制数据库对象身份

对象导航树中的“复制名称”→“复制全限定名”按数据库方言引用每一级对象标识符，例如 `"sales"."Order Details"`。多选时按树中顺序逐行复制。仅在节点携带完整连接/目录/模式身份且所选对象均支持 SQL 限定名时提供该操作；不使用树上的显示路径猜测名称。列、例程及包成员会包含其父对象名，例程签名和 package body 不属于限定名。

查询结果表头菜单中的“复制列元数据”只复制列信息（名称、类型、来源、可空性、注释），不复制单元格数据，也不会为复制额外读取数据库或 LOB。

## 值表现与原值

高级复制的值表现可选择兼容默认、显示值、编辑值或原生值。兼容默认保持原有格式行为；显示值和编辑值分别采用网格显示/编辑格式；原生值使用数据库驱动解码后的值，并保留无法由 JavaScript 数字精确往返的十进制数值。MongoDB BSON 值保持其外部语义，不把内部传输标记复制到剪贴板。SQL 和内部回粘载荷不因文本格式变化而改写。
