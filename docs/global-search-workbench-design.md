# DBX 全局搜索工作台

## 设计目标

快捷搜索承担 DBX 的全局导航职责：从一个入口定位连接、数据库、Schema、表、字段、注释、SQL 文件、文件内容和命令，并在结果出现时直接告诉用户对象上下文、数据来源和 Enter 的默认动作。

本轮优先完成高保真三栏工作台和类别导航，并复用现有 `useQuickOpen` 数据链路、取消机制和 App 打开路由。

## 工作台布局

- 顶部：搜索输入、对象/文件内容模式、搜索设置。
- 类别栏：全部、连接、数据库、对象、字段、SQL 文件、文件内容、命令，显示实时数量。
- 左栏：连接范围、连接状态、快捷过滤条件。
- 中栏：按类别过滤后的结果列表，结果行显示类型、来源、数据库上下文和匹配高亮。
- 右栏：选中结果预览，显示数据库/Schema/表/字段关系、注释、来源和默认打开动作。
- 底部：结果数量和键盘操作说明。

窗口较窄时连接范围保留为紧凑选择器，对象预览显示在结果下方；文件内容预览和编辑区移至结果下方，保存与取消始终可用，缩放窗口不会重建编辑器。文件内容模式继续使用按文件分组的内容结果和已有预览组件。空查询时显示当前连接、最近文件、最近对象和最近命令，并优先恢复最近打开的目标。

## 类别行为

- `全部` 显示统一结果池。
- `连接` 显示连接目标和连接状态。
- `数据库` 显示数据库和 Schema。
- `对象` 显示表、视图、函数、过程等数据库对象。
- `字段` 显示字段名、所属表、Schema 和字段注释。
- `SQL 文件` 显示保存 SQL 和外部 SQL 文件。
- `文件内容` 切换到现有文件内容搜索模式。
- `命令` 显示插件命令和插件工作台。

`⌘/Ctrl + 1…8` 可以切换类别。类别切换不会改变原始查询，只改变结果视图和当前选中项。内容搜索中输入结构化对象过滤条件时会自动切回对象模式，避免把 `kind:column` 当作文件正文搜索。

## 结果与操作

字段默认操作是“打开结构并定位字段”；表和视图默认打开数据；函数和过程默认打开源代码；SQL 文件打开编辑器；命令直接执行；未连接连接默认进入连接流程。右侧预览显示第二动作提示，例如表可以使用 `⌘Enter` 打开结构，字段可以使用 `⌘Enter` 打开所属表数据。

## 最近工作与生命周期

最近打开的对象、SQL 文件、内容命中和命令会保存轻量快照，最多保留 12 条，30 天后自动过期。已删除连接和失效插件目标不会恢复到首页；远程对象不在搜索时自动重新连接，真正打开时仍由目标路由完成权限和对象有效性校验。关闭窗口会取消等待中的远程和文件搜索，并通过 generation 丢弃迟到结果。

数据库元数据另外保存 last-known Quick Open 快照，覆盖已经加载过的数据库、Schema、表/视图/物化视图、字段和 routine。快照使用连接配置指纹隔离连接编辑，并在 30 天后过期；连接关闭时只清理当前会话的内存树，不删除这份离线元数据。已有完整的侧栏表索引也会继续作为离线表和视图来源，过期索引仍可作为 last-known 结果展示。真正删除连接时会使读写 generation 失效，并清理 Quick Open 快照、表索引和 manifest。搜索阶段只读取本地缓存，结果使用 `cache` 来源标识；用户打开结果时才按现有路由显式连接并重新校验对象。

类别栏数字统计当前合并结果池中的条目，可能同时包含内存树、last-known 快照、完整表索引和远程命中，不代表数据库全量实时对象数。文件内容类别仍只在内容模式执行实际文件扫描；后端会返回已找到的部分结果和结构化文件系统错误，界面保留部分结果并提供重试，取消搜索不会显示为失败。
