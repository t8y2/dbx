# 首页展示模式

DBX 在没有打开查询标签时，可以展示产品介绍或工作区概览。用户可以在「设置 → 外观 → 首页」切换，介绍页底部的「首页设置」也会直接定位到该选项。修改遵循现有设置的应用、取消和持久化流程。

## 两种模式

- **工作区概览（默认）**：保留原有连接统计、快速连接和保存的 SQL 历史，适合希望快速回到日常工作的用户。
- **DBX 介绍**：展示产品说明、连接管理、SQL 编辑、数据浏览与传输、AI / MCP 能力，以及新建连接、导入连接等固定入口。不展示个人连接名称、地址、数量、已连接状态、数据库类型统计或 SQL 历史；查询入口继续由现有工具栏提供。适合在展示、录屏或共用屏幕时不想露出个人数据的用户主动开启。

介绍页采用主题颜色、留白和响应式布局，兼容深浅主题。首页设置支持设置搜索、配置导入导出和恢复默认。模式值为 `welcomePageMode: "intro" | "workspace"`，缺失或无效配置回退为工作区概览。

### 默认值迁移

介绍页曾在 v0.6.33 短暂作为默认值。当前版本通过 `welcomePageModeDefaultVersion` 标记把默认值迁回工作区概览：没有该标记的历史设置（包括 v0.6.33 期间被整体快照写入的 `intro`）在启动时一次性重置为工作区概览并落盘；标记为当前版本后，用户显式选择的介绍页会跨重启保留。

## 实现与边界

`App.vue` 在设置加载完成前保持工作区模式；介绍模式下首页统计、快速连接和 SQL 历史计算直接返回零值或空列表，不读取或排序这些个人数据。`WelcomeScreen.vue` 个人数据 props 可省略，介绍分支与工作区分支分别渲染。介绍页的按钮布局也不依赖是否已连接数据库。

该选项只控制**中央空白首页**，不隐藏连接侧栏、已打开的标签、工具栏或用户主动打开的历史窗口，也不删除连接与历史数据。展示或录屏前如需隐藏整个工作区的个人信息，仍需检查这些区域；这项设置不是全局隐私模式。

## 验收重点

1. 无配置、旧配置和无效值均显示工作区概览；保存介绍页模式后重启恢复该选择；v0.6.33 存量的 `intro`（无版本标记）首次启动被迁回工作区概览并持久化。
2. 介绍页不出现连接统计、名称、地址和 SQL 历史，连接或历史数据变化不改变介绍页内容。
3. 切换到工作区概览恢复原有统计与操作，设置取消不保存，应用后立即生效。
4. 外观恢复默认、全局恢复默认、导入导出与设置搜索正确覆盖该选项。
5. 中英文、深浅主题、窄窗口和键盘操作可用，选项提供可访问的选中状态。
